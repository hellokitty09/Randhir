## 2026-06-08 - Unthrottled scroll event listeners
**Learning:** This static website project's hybrid animation approach uses an unthrottled scroll event listener in `script.js` to trigger layout-heavy calculations (`getBoundingClientRect` inside `isInViewport`). This can cause layout thrashing and negatively impact performance (jank) during scroll events, especially since it fires continuously without rate limiting.
**Action:** Always throttle scroll or resize events that read layout properties. Use `requestAnimationFrame` with a boolean flag to rate-limit execution to the display refresh rate (usually 60fps). Furthermore, pass `{ passive: true }` when registering the listener if the event's default action doesn't need to be prevented, allowing the browser to optimize scrolling.
