## 2024-05-24 - Throttling Scroll Event Listeners
**Learning:** The codebase uses a hybrid animation approach: modern pages use `IntersectionObserver`, while `contact.html` uses an external `script.js` for scroll-triggered staggered animations. The original scroll event listener in `script.js` triggered `handleAnimation` (which uses `getBoundingClientRect()`) synchronously on every scroll event. This causes main-thread blocking and layout thrashing, reducing frame rates, especially on mobile devices.
**Action:** Throttled scroll event handlers using `requestAnimationFrame` and a boolean flag (`isScrolling`), and registered the listener with `{ passive: true }` to explicitly tell the browser the scroll handler won't call `preventDefault()`, thus improving scrolling performance. In the future, prefer `IntersectionObserver` when applicable for simpler and more performant viewport checking without manual scrolling event logic.
