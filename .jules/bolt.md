## 2024-05-18 - Hybrid Animation Patterns and Scroll Throttling
**Learning:** This codebase uses a hybrid approach to scroll animations. Modern pages (`index.html`, `destinations.html`, `about.html`) use performant `IntersectionObserver` directly in inline scripts. However, legacy external scripts (`script.js` used by `contact.html`) still rely on raw `scroll` event listeners combined with layout-thrashing `getBoundingClientRect()` calls to trigger staggered animations.
**Action:** When working on generic JS files in this project, be aware that they might be using older, unoptimized patterns compared to the inline scripts. Always throttle scroll events using `requestAnimationFrame` when `IntersectionObserver` isn't feasible to retrofit, and look out for layout-heavy calculations on scroll.
