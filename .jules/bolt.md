## 2024-05-24 - Unthrottled Scroll Event Listeners Causing Layout Thrashing
**Learning:** The project uses an unthrottled scroll event listener in `script.js` to trigger staggered animations. Inside this listener, it calls `getBoundingClientRect` which forces layout calculation synchronously on every scroll tick. This blocks the main thread, leads to dropped frames (jank), and prevents the browser from optimizing scrolling.
**Action:** Always throttle scroll and resize event listeners, particularly those triggering layout-heavy calculations (e.g., `getBoundingClientRect`). Wrap the handler in `requestAnimationFrame` guarded by an `isTicking` flag, and register the listener with `{ passive: true }` to maintain 60fps performance and allow the browser to decouple scrolling from the main thread execution.
