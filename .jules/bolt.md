## 2026-09-21 - Unused gallery-item Animation Dead Code
**Learning:** The external script.js file contains an entire section dedicated to sliding animations and hover effects for '.gallery-item' elements. However, these elements do not exist anywhere in the codebase (across index.html, about.html, destinations.html, contact.html, or styles.css). The code executes a scroll event listener and queries the DOM unnecessarily, degrading performance by attaching a scroll handler and calculating bounding client rects (if elements existed, though here it's just iterating an empty NodeList).
**Action:** When auditing external JS files on static sites, verify that the selectors they target actually exist in the HTML. Dead code, especially scroll handlers, should be removed to avoid unnecessary computation.
